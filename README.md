# RB Eyewear

A full-stack e-commerce demo project built to showcase frontend and backend development skills.

*This is a portfolio project, not a real online store.*

## 🌐 Live Demo

[**Visit RB Eyewear ↗**](https://rbeyewear.netlify.app/)

A demo account is available on the login page to explore the admin dashboard. Admin actions are restricted.

> **Note:** The project is hosted using free-services. The backend may go idle after periods of inactivity, so sometimes the first request can take up to a minute while the server starts.

## ✨ Features

- Product browsing, categories, search, filtering and sorting.
- Shopping cart, wishlist, and order management.
- User authentication.
- Admin dashboard for products, categories, orders and users.
- Read-only demo access.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **Backend:** ASP.NET Core Web API, C#.
- **Database:** PostgreSQL.
- **Libraries:** TanStack Query, Zustand, Axios, Entity Framework Core.
